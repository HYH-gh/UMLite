# 更新日志

> 版本号规则：`1.XX`，其中 `XX` 是 git 提交次数（`git rev-list --count HEAD`）。
> 每次提交前在顶部追加一节，然后执行 `node tools/sync-changelog.mjs` 生成 `js/changelog.js`，
> 页面读的就是生成后的那份数据；`node tests/run.mjs` 会校验三者（本文件 / 页面数据 / README 版本号）是否一致。

## 1.21 · 2026-11-06
- 代码区上方新增文件区：多张图分目录管理，拖动分隔条调高度，也可整体隐藏
- 目录树：新建 / 重命名 / 删除目录与图，鼠标拖动换层级（目录不能拖进自己的子孙）
- 图的名称跟着代码里的 `@diagram` 标题走，10 种图各有线条图标；空图显示「新建图」
- 单图导入落到当前选中目录；新增整个项目的 JSON 导入 / 导出，导入时可选「覆盖」或「插入为子目录」
- 整棵树存 localStorage，刷新、关页面都不丢
- 新增 13 项页面级断言（命名与图标、增删改、拖动、往返导入、存档、示例不覆盖当前图）

## 1.20 · 2026-11-05
- 新增更新公告弹窗：点右下角版本号可随时查看历次更新
- 首次打开（或版本号变化后）自动弹出一次，已读版本记在 localStorage，之后不再打扰
- 版本号规则落地为 `1.XX`（XX = 提交次数），README / 本文件 / 页面三处同步
- 更新内容由 `docs/CHANGELOG.md` 生成到 `js/changelog.js`，页面直接读取
