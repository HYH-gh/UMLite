# 更新日志

> 版本号规则：`1.XX`，其中 `XX` 是 git 提交次数（`git rev-list --count HEAD`）。
> 每次提交前在顶部追加一节，然后执行 `node tools/sync-changelog.mjs` 生成 `js/changelog.js`，
> 页面读的就是生成后的那份数据；`node tests/run.mjs` 会校验三者（本文件 / 页面数据 / README 版本号）是否一致。

## 1.25 · 2026-11-17
- 样式解耦：新增 `js/theme.js`，把颜色 / 字体 / 线宽 / 圆角 / 阴影 / 渐变收敛成一份主题 token 表；`js/render.js` 只留几何与结构，绘制代码里不再有硬编码色值（含包、部署节点、构件、数据库、便签、组件、连线和顺序图）
- 画布内联样式改由 token 表生成（字号滑块照常统一缩放，导出 SVG / PNG 自动带上当前配色）
- 新增「简约」配色（参考 Enterprise Architect）：象牙→浅褐渐变填充、黑色 1px 描边、右下轻微投影、顺序图浅青头部、灰底泳道；文字改宋体（西文走 Times New Roman，避免比版面预留宽度更宽而顶出边框），图内不铺底纹、直接用页面画布底色
- 预览工具栏新增「🎨 配色」按钮，色彩 / 简约随时切换；配色只影响显示，代码、坐标、布局一概不变；选择记在 localStorage，也支持 `?theme=plain` 直接打开
- 顺序图简约配色：控制 / 实体 / 边界类图标圆圈、激活条与激活焦点改填对象框同款浅青蓝渐变（角色那一列仍是象牙色），激活条与激活焦点加 3px 圆角
- 顺序图：自动激活条改为「每位参与者一整条」，不再按消息间隔断成几截，中间空档也一并覆盖（EA 那种整列连续的观感）；发起者仍从生命线顶开始，`->*` 创建出来的对象仍从被创建那一行开始
- 顺序图：默认布局更紧凑 —— 列宽按参与者标签的实际渲染宽度算（去掉固定 140 下限）、列间距 64 → 14、左右留白 44 → 32，整图宽度约缩窄四成，缩放适配后文字明显变大
- 顺序图：实心消息箭头改用类图那套三角形比例（长 11、半张角 0.36），比原来的短钝箭头更尖
- 结构整理：`index.html` 顶部那 26 行内联 SVG 图标库搬到 `js/icons.js`，启动时注入到 `<body>` 首个节点；页面结构回到「header + 面板」，`<use href="#ic-*">` 引用方式不变，双击 `index.html`（`file://`）照样显示图标（浏览器不允许跨文件引用 `<symbol>`，所以不能做成外部 `.svg`）
- 修复：活动图带泳道时画布尺寸没算进泳道，缩放适配会把泳道裁掉一截
- 新增 4 项页面测试（两套配色 token 一致、切换不动模型、渐变 / 投影定义、选择记忆），共 85 项
