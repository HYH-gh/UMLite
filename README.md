# UMLite · 文本驱动 UML 绘图工具

**UMLite** 是一个纯前端、文本驱动的 UML 绘图工具。你只需在左侧编辑器中书写简单的文本描述，右侧预览区域便会**实时**渲染出对应的 UML 图形。无需安装、无需注册、无需网络，一个 HTML 文件搞定所有 UML 绘图需求。

> 📄 **一句话用法**：打开 `UMLite.html` → 写代码 → 自动出图 → 导出 PNG / SVG。

---

## ✨ 功能特性

- **纯前端，零依赖** — 单个 `.html` 文件，双击即用，离线可用
- **实时渲染** — 编辑代码即刻预览，无需手动触发
- **10 种 UML 图** — 类图、用例图、活动图、时序图、E-R 图、状态图、组件图、部署图、对象图、包图
- **力导向布局** — 元素自动排布，无需手动指定坐标
- **交互式画布** — 拖拽元素、滚轮缩放、空白处拖拽平移
- **智能代码补全** — 图类型支持中英文别名
- **SVG / PNG 导出** — 矢量图高清导出，PNG 支持 2x 缩放
- **语言规范文档** — 内置完整语法文档，一键下载 `.md`
- **示例系统** — 每种图类型均带预设示例，一键载入
- **中文友好** — 完整的**中文**标识符支持，文档和界面均为中文
- **可选系统边界框** — 用例图支持 `boundary` + `:boundary` 标记

## 🚀 快速开始

1. 在浏览器中打开 `UMLite.html`
2. 从顶部下拉菜单选择一个示例（如「类图 · 电商系统」）
3. 左侧代码区即显示对应 DSL 代码，右侧实时渲染出 UML 图形
4. 任意修改代码，画布自动更新
5. 点击「下载 PNG」或「下载 SVG」导出结果

### 最小示例

以下是一个完整的类图 DSL：

```
@diagram class "Hello UML"

class Hello {
    + sayHello(): String
}

class World
Hello --> World : greet
```

| 图类型 | 关键字 | 示例 |
|--------|--------|------|
| 类图 | `class` | 类、接口、抽象类、枚举、继承、实现 |

| 对象图 | `object` | 对象、属性快照 |
| 包图 | `package` | 包、包间依赖 |

## ⌨️ DSL 语法速览

### 文档结构

```
@diagram <类型> ["图标题"]

// 注释以 # 或 // 开头
语句 1
语句 2
```

### 关系运算符

| 运算符 | 含义 |
|--------|------|
| `-->` | 有向关联 |
| `--` | 无向关联 |
| `--|>` | 继承 / 泛化 |
| `..|>` | 接口实现 |
| `..>` | 依赖 |
| `*--` | 组合 |
| `o--` | 聚合 |
| `..` | 虚线关联 |

### 各图类型语法要点

**类图：** `class 名称 { 成员 }` / `interface 名称 { 成员 }` / `abstract class 名称`
**用例图：** `actor 角色` / `usecase 用例 [:boundary]` / `boundary "系统名称"`
**活动图：** `start` / `:动作;` / `if(条件)`...`else`...`endif` / `while`...`endwhile` / `note:文本`
**E-R 图：** `entity 名称 { * 字段 }` / `||--o{` / `||--|{` / `||--||`
**时序图：** `participant 名称 [as 别名]` / `A -> B : 消息` / `A --> B : 返回`
**状态图：** `state 名称` / `A --> B : 事件` / `[*]` 表示起始/终止

## 🏗️ 技术架构

UMLite 是完全运行在浏览器中的单页应用，采用**三层架构**：

```
┌──────────────────────────────────────┐
│           渲染层 (SVG)               │
│  buildGraphContent / paint / drawEdge│
├──────────────────────────────────────┤
│           布局层 (Force)              │
│  layoutForce / normalizeToOrigin     │
├──────────────────────────────────────┤
│           解析层 (DSL Parser)         │
│  parseDSL / parseClassLike           │
├──────────────────────────────────────┤
│           编辑器 + 交互层             │
│  textarea / Pointer Events / Canvas  │
└──────────────────────────────────────┘
```

- **解析层**：正则表达式 + 行解析器，将 DSL 文本转换为结构化模型
- **布局层**：力导向布局算法，自动计算节点坐标；用例图支持边界框分离布局
- **渲染层**：纯 SVG 渲染，支持拖拽、缩放、平移交互
- **零依赖**：不使用任何第三方库，纯原生 JavaScript + SVG
